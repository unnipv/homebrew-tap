# pokemon slowdown — Homebrew tap

```sh
brew install unnipv/tap/pokemon-slowdown
```

The formula in `Formula/` is generated automatically by
[GoReleaser](https://goreleaser.com) from the
[pokemon-slowdown](https://github.com/unnipv/pokemon-slowdown) release
workflow. Do not edit it by hand — changes will be overwritten on the next
release.

Prefer a different install method?

```sh
go install github.com/unnipv/pokemon-slowdown/cmd/slowdown@latest
```

or grab a binary from the
[releases page](https://github.com/unnipv/pokemon-slowdown/releases).
